# Moon Club 0.23.0: "Under the hood"

This one is mostly engine work, like a pit stop in Cars: same car, new tires, and a lot less smoke.

**Old levels play again.** A level you'd started on an earlier day but hadn't won yet was counted as a "new" level each day, so once the day's three were used it hit the break screen. Any level you've opened before now stays free for good, like a library card that never expires. Only brand-new levels count toward the daily three.

**Snappier everywhere.** Earning Moon points used to make the whole World map redraw itself on a hidden tab, like Dory starting the conversation over every few seconds. Now hidden tabs sit still until you open them, and the app's shortcuts (open a quest, the locker, a tab) no longer wake every screen. On our test run, ten point bankings went from 757 screen redraws to 109, and main-thread work per frame dropped about 70%.

**Sturdier breaks.** Sponsor breaks use their own private connection (no cookies, no cache, short timeouts), only show https pictures under 4 MB, and if a sponsor's video can't play, Luna's quiz takes over instead of a black box.

**A flight recorder, on this device only.** For grown-ups → Diagnostics shows the version, slow moments this week, memory, Apple's daily performance reports, and recent events like levels opened, breaks and Pass changes. Nothing leaves the device unless a grown-up taps Share. It's the Apollo 13 approach: when something goes wrong, we can see exactly which tank.

## What to test
- **Old levels:** start a level past level 20 one day, then on another day after using the three new levels, open that same level again. It plays with no break screen.
- **Speed:** earn points on Story, then switch to World. It should feel instant, with no stutter.
- **Breaks:** take a break with no network. Luna's quiz shows and Collect still works.
- **Diagnostics:** For grown-ups → Diagnostics → Recent events shows levels opened and breaks. Share sends a text report.
